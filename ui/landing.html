What this does not say

  • It is not a claim about skills in general. Each task asserts a house convention that is arbitrary by construction, roughly fourteen checks deep, and nowhere in the prompt. An agent without the setup has no way to guess it, so the no-setup arms sit near the floor and the gap measures convention compliance rather than general task ability.
  • It is not one rule doing the work. Rewriting every em dash in all 141 failed no-setup runs, then re-running the untouched verifiers, rescued none of them. The failures spread across 31 distinct messages.
  • n equals one machine. Every task is drawn from one person's real session logs, so this measures this setup, not setups in general.
  • Discovery and use are measured together. Prompts are identical across arms and never mention that a skill exists, so the with-setup arms show what an agent finds and then applies, not use alone.
  • The verifier is blind. It is a fixed script that runs against the finished workspace and never sees which arm produced it.
