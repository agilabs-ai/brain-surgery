# Brain Surgery report design system

Brain Surgery is an AGI Labs surface, not a separate visual brand.

## Tokens

- Background: `#FFFFFF`
- Primary text: `#050505`
- Muted text: `#6B6B6B`
- Border: `#E5E5E5`
- Accent: AGI Labs blue `#154CFF`
- Soft accent: `#EEF3FF`
- Font: Inter/system sans fallback
- Radius: 9px for controls; 12–14px only for report containers

No gradients, medical green, neon palette, decorative shadows, or new brand typography.

## Hierarchy

1. measured current → tested score
2. one-sentence interpretation
3. share action
4. workflow-level evidence
5. three concise findings
6. detailed evidence behind a control

The local and public summary should look almost identical. Privacy comes from a smaller public payload, not from visually hiding private elements.

## Brain gauge

The left hemisphere represents current task pass rate in black; the right hemisphere represents tested pass rate in AGI Labs blue. Fill height is data-driven. The bottom rule repeats the comparison in a minimal linear gauge.

Unknown data is an unknown state, not 0%.
